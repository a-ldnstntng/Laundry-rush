# Sampayan Rush — Rooftop Laundry Panic!

An isometric retro pixel-art Filipino arcade game where you race to rescue laundry (*sinampay*) from the rooftop clothesline before the sudden monsoon downpour (*buhos ng ulan*) soaks everything and **Nanay** scolds you!

## Features
- **3 Escalating Yugto (Stages)**:
  - **Yugto 1 (*Maaliwalas* / Clear Skies)** — Accompanied by a 3/4 waltz chiptune arrangement of *"Bahay Kubo"*.
  - **Yugto 2 (*Hanging Habagat* / Monsoon Winds)** — Gusts blow garments off the line; accompanied by a brisk 2/4 polka-march chiptune arrangement of *"Leron, Leron Sinta"*.
  - **Yugto 3 (*Signal No. 1!* / Typhoon Panic)** — Fast-moving storm and heavy gusts; accompanied by a high-energy chiptune arrangement of *"Magtanim Ay 'Di Biro"*.
- **Authentic Filipino Garments**: *Daster ni Nanay*, *Sando*, *School Uniform*, *Maong*, *Basketball Jersey*, *Kumot (Floral Blanket)*, *Short Pambahay*, and *Bimpo*.
- **Bilingual Support**: Instant Tagalog (`TL`) and English (`EN`) toggle.
- **Zero External Assets**: 100% self-contained HTML5 Canvas 2.5D isometric renderer (`engine.js`, `game.js`) and procedural Web Audio synthesizer (`audio.js`).

## Deployment (Vercel)
This project is a zero-configuration static site (`index.html`, `engine.js`, `audio.js`, `game.js`). Connect the repository directly to **Vercel** with Framework Preset set to **Other** (no build command required).
